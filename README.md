# হিসাবের খাতা — সমবায় খামার ব্যবস্থাপনা (Firebase সংস্করণ)

গরু, মুরগি ও ছাগল খামারের সমবায় হিসাব — সদস্যদের জমা/উত্তোলন, খরচ, আয়, লাভ-ক্ষতি রিপোর্ট, WhatsApp
নাম্বার তালিকা, PDF ডাউনলোড, এবং PIN-ভিত্তিক এডিট নিয়ন্ত্রণ। Firebase Firestore ব্যবহার করে সব
ডেটা স্থায়ীভাবে সংরক্ষিত হয় এবং সবার পাতায় সাথে সাথে (রিয়েল-টাইম) আপডেট হয়।

## ১. Firebase প্রজেক্ট তৈরি করুন

1. https://console.firebase.google.com -এ যান, "Add project" চেপে একটি প্রজেক্ট বানান (Google
   Analytics লাগবে না, বন্ধ রাখতে পারেন)।
2. প্রজেক্ট খোলার পর বাম পাশের মেনু থেকে **Build → Firestore Database** এ যান, "Create database"
   চেপে তৈরি করুন। শুরুতে "Start in test mode" বা "production mode" যেকোনোটা বেছে নিলেই হবে
   (নিচে ধাপ ৪-এ নিয়ম বসিয়ে দেব)। একটি লোকেশন (যেমন `asia-south1` — মুম্বাই, বাংলাদেশের কাছাকাছি)
   বেছে নিন।
3. এরপর **Project settings** (⚙️ আইকন) → নিচের দিকে "Your apps" সেকশনে যান → ওয়েব আইকন (`</>`)
   চেপে একটি Web App যোগ করুন (নাম যা খুশি দিন)। এটি করলে একটি `firebaseConfig` অবজেক্ট দেখাবে —
   সেটি কপি করুন।

## ২. কনফিগ বসান

`src/firebase.js` ফাইল খুলুন এবং `firebaseConfig` অবজেক্টের ভেতরের মানগুলো (apiKey, projectId
ইত্যাদি) আপনার কপি করা মান দিয়ে প্রতিস্থাপন করুন।

## ৩. প্রজেক্ট চালু করুন (নিজের কম্পিউটারে পরীক্ষা)

টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে:

```bash
npm install
npm run dev
```

এরপর টার্মিনালে দেখানো লোকাল লিংকে (যেমন `http://localhost:5173`) ব্রাউজারে খুলুন।

## ৪. Firestore নিরাপত্তা নিয়ম (Security Rules) বসান

`firestore.rules` ফাইলে সহজ নিয়ম দেওয়া আছে (সবাই পড়তে/লিখতে পারবে — অ্যাপের PIN শুধু UI-তে
নিয়ন্ত্রণ করে, ডেটাবেজ স্তরে নয়)। এটি Firebase কনসোলে বসাতে:

- **Firestore Database → Rules** ট্যাবে গিয়ে `firestore.rules`-এর ভেতরের কনটেন্ট কপি-পেস্ট করে
  **Publish** চাপুন।

  অথবা Firebase CLI দিয়ে (নিচে দেখুন) `firebase deploy --only firestore:rules` চালান।

## ৫. ইন্টারনেটে প্রকাশ (Deploy) করা

### বিকল্প ক: Firebase Hosting (Firebase CLI দরকার)

```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # প্রজেক্ট বেছে নিন, public directory: dist, single-page app: yes
npm run build
firebase deploy
```

Deploy শেষে একটি লিংক পাবেন (যেমন `https://your-project.web.app`) — এটাই সবার সাথে শেয়ার করার
লিংক।

### বিকল্প খ: Vercel / Netlify (সহজ, GUI দিয়ে)

```bash
npm run build
```

এতে `dist/` ফোল্ডার তৈরি হবে — সেটি Vercel বা Netlify-তে "drag and drop" করে আপলোড করলেই সাইট
লাইভ হয়ে যাবে। GitHub-এর সাথে যুক্ত করলে ভবিষ্যতে আপডেট দেওয়াও সহজ হবে।

## ৬. প্রথমবার ব্যবহার

সাইট খোলার পর হেডারে "শুধু দেখা — এডিট মোড" বাটনে চাপুন। প্রথমবার একটি নতুন PIN সেট করতে বলা
হবে — এটি সেট করলে আপনি এডিট মোডে চলে যাবেন এবং যে কেউ এই PIN জানলে এডিট করতে পারবে। এই PIN
বিশ্বস্ত কমিটি সদস্যদের সাথেই শুধু শেয়ার করুন।

## ডেটা কীভাবে সংরক্ষিত হয়

- `members` — সদস্যদের তালিকা
- `whatsappContacts` — WhatsApp নাম্বার তালিকা
- `farms/cow/deposits`, `farms/cow/expenses`, `farms/cow/incomes` — এবং একইভাবে `chicken`,
  `goat`-এর জন্য
- `settings/app` — PIN সংরক্ষিত থাকে এখানে

সবগুলো Firestore-এ রিয়েল-টাইম listener (`onSnapshot`) দিয়ে সাবস্ক্রাইব করা, তাই কেউ কিছু
যোগ/মুছলে সাথে সাথেই (সাধারণত এক সেকেন্ডেরও কম সময়ে) বাকি সবার পাতায় দেখা যাবে — পেজ রিফ্রেশ
করার দরকার নেই।

## নিরাপত্তা জোরদার করা (ঐচ্ছিক, ভবিষ্যতের জন্য)

বর্তমান ব্যবস্থায় PIN শুধু UI-স্তরে কার্যকর — কেউ চাইলে প্রযুক্তিগতভাবে সরাসরি Firestore API
কল করে ডেটা পরিবর্তন করতে পারবে (যদিও সাধারণ ব্যবহারকারীর পক্ষে এটা করা কঠিন)। আরও শক্তিশালী
নিরাপত্তা চাইলে ভবিষ্যতে যোগ করা যায়:

- Firebase Authentication (ইমেইল/পাসওয়ার্ড বা ফোন-নম্বর লগইন) চালু করে
- Firestore rules-এ `allow write: if request.auth != null && request.auth.uid in [...]` এর
  মতো নিয়ম বসিয়ে শুধু নির্দিষ্ট লগইন করা ব্যবহারকারীদের লেখার অনুমতি দেওয়া

এটা করতে চাইলে জানাবেন, পরের ধাপে যোগ করে দেওয়া যাবে।

## PDF ডাউনলোড কীভাবে কাজ করে

প্রতিটি তালিকা/রিপোর্টের "PDF ডাউনলোড" বাটন ব্রাউজারের প্রিন্ট ডায়ালগ খোলে — সেখান থেকে
"Save as PDF" বেছে নিলেই ডাউনলোড হয়ে যায়। এটি সরাসরি ব্রাউজারের সুবিধা ব্যবহার করে বলে বাংলা
ফন্ট ঠিকমতো দেখায়, কোনো অতিরিক্ত সেটআপ লাগে না।
